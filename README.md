# 3D Molecular and Materials Generation Models Review

A curated literature collection covering 3D molecular and materials generation with GANs, VAEs, autoregressive models, diffusion models, flows, energy-based models and multimodal approaches.

## Browse the collection

- [Model catalogue: papers and code by category](MODEL_CATALOGUE.md)
- [Download the Excel dataset](https://github.com/plh1234-syn/3D-molecular-generation-models-review/raw/refs/heads/main/3D_molecular_generation_models.xlsx)

The detailed tables are in **MODEL_CATALOGUE.md**. Paper and code/resource links are clickable in the catalogue and in the downloaded workbook.

## Dataset

The workbook contains a Summary worksheet and 11 category worksheets. Summary has **235 data rows** (236 including its header). The **269 year-bearing category rows** include overlapping category memberships and repeated entries; they do not represent 269 additional or independent models. See the [data notes](MODEL_CATALOGUE.md#data-notes) for the complete counting convention.
